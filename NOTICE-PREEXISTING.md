# Notice of pre-existing work

The Bone Health Tracker concept, its earlier prototype, its visualization concepts, and a
custom BMD report parser capable of handling multiple bone sites and report formats existed
before this CockroachDB x AWS hackathon project.

Those assets are not represented as new hackathon work. If any pre-existing implementation
is imported, it must remain isolated under `legacy/` or a clearly identified package and
retain provenance including its original name and version.

The new BoneTwin work is the agentic-memory architecture and implementation: the
CockroachDB-backed memory model, Memory Trust Engine, hybrid retrieval, AWS production
workflow, human review loop, Memory Impact Trace, evaluation framework, and public demo.

No pre-existing parser source has been copied into this Phase 0 repository.
