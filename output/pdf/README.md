# BoneTwin local demo documents

These PDFs are generated by `scripts/generate_demo_documents.py`. Every document is
fictional, contains no real patient data, and is visibly marked `SYNTHETIC DEMO - NOT A
MEDICAL RECORD`.

Recommended local walkthrough:

1. Upload `bonetwin-demo-dxa-2026.pdf` to exercise the latest-report workflow.
2. Review the three extracted measurements and their source evidence.
3. Run the trusted comparison and resolve its human-review task.

The 2019 and 2022 variants are supplied for parser and duplicate-upload demonstrations.
They are not clinical examples and must not be used for health decisions.
