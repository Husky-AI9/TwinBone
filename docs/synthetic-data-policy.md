# Synthetic-data-only policy

BoneTwin's public demo, local fixtures, automated tests, screenshots, logs, examples, and
evaluation datasets must use plainly synthetic or fully de-identified information.

Do not add names, addresses, contact details, medical record numbers, account identifiers,
real report images, production OCR, presigned URLs, or any data copied from an identifiable
person. Synthetic records must avoid combinations that could reasonably identify a real
individual.

The project is for document understanding, longitudinal organization, and clinical-review
preparation. Synthetic examples must not present diagnoses, medication changes,
fracture-risk predictions, or autonomous treatment recommendations.

If data provenance is uncertain, do not commit or process it. Replace it with a fabricated
fixture and document the fixture-generation method.
